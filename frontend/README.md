# YouTube Transcript Studio — frontend

Next.js app for YouTube Transcript Studio. See the [root README](../README.md) for setup, environment variables, and Vercel deployment.

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
npm run dev                  # http://localhost:3000
npm test && npm run build
```
